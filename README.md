# Прогноз продаж 82580

Взял Bathroom Metal Sign из Online Retail. Сравнил скользящее среднее, метод Холта и бустинг. Для бустинга обучил отдельную модель на каждый горизонт. Ошибки считал на скользящих окнах.

На днях лучший результат получил у бустинга. Его MAE держалась около 11–12 штук, но пики продаж он часто занижал. На неделях бустинг выиграл на шаге 1, Холт на 4 и 8.

На месяцах бустинг оказался первым на обоих горизонтах. Его MASE вырос примерно с 1 до 1,14. В тесте всего четыре месяца, поэтому этой разнице сильно доверять сложно.

Ноутбук можно открыть из этой папки командой `uv run jupyter lab`.
